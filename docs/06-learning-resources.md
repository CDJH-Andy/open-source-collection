# 学习与资源

> 这一类是 GitHub 上 star 最高的一批仓库——它们大多不是软件，而是一份被人肉维护的目录。
> 这说明一件事：**在信息过载的时代，经过人工筛选的清单比搜索更有价值。**

## 先看结论：按目标挑

| 你的目标 | 从这里开始 | 周期 |
|---|---|---|
| 零基础转行做开发 | **freeCodeCamp** + **developer-roadmap** | 6–12 个月 |
| 想弄清某个技术底层怎么实现 | **build-your-own-x** | 每个项目 1–2 周 |
| 补计算机基础（网络、操作系统） | **CS-Notes** + **system-design-primer** | 3–6 个月 |
| 准备面试 | **coding-interview-university** + **tech-interview-handbook** | 2–3 个月 |
| 找免费电子书 | **free-programming-books** | 随时查 |
| 找现成的 API 做练手项目 | **public-apis** | 随时查 |
| 想要「某个领域所有好东西」的索引 | **awesome 系列** | 随时查 |

## 上手建议

1. **别把收藏当学习。** 收藏 20 个仓库的成就感，约等于学完 0 个。
2. **路线图只用来定位，不用来崇拜。** 挑一条，走到能做出东西为止，再回头看别的分支。
3. **build-your-own-x 是最好的祛魅工具。** 自己写一遍 Redis 或 Git，你会突然明白很多「高级」的东西其实不神秘。
